# 大枠プロット・テンプレート

大枠プロットは、1シリーズ・1キャラ本編につき1枚作るマスター資料です。ここが固まらないうちに話数展開に入らないこと。

## テンプレート

```
■タイトル：〇〇（シリーズ名） ○○（キャラ名） 本編
■シナリオ基本仕様：全○話／1話○○字／選択肢○個／END：○○END・○○END（2種）

■3行ストーリー：
（作品全体を3行で。「〇〇な彼の目的は〇〇！だけど〇〇と気づき〇〇するストーリー」の型を基本に）

■恋愛テーマ：（一行キャッチ）
■サイトならではのネタ：（媒体・設定特有のフック。診断アプリ、婚活、同居など）

■登場人物／攻略キャラ：
■ヒロイン：

■大枠（起承転結）
起（1〜○話）：（一言キャッチ）
承1（○〜○話）：（一言キャッチ）
承2（○〜○話）：（一言キャッチ）
転・結（○〜○話）：（一言キャッチ）

■ヒロインのA⇒B：
A（開始時の価値観）：
B（終了時の価値観）：
（攻略対象側にもA⇒Bがあれば併記）

■敵：（恋を阻むもの。ミスマッチ／過去の傷／身分差など）
■味方：（後押しするもの。診断結果／アプリの仕組み／友人など）

■イベントラベル：
・価値観が変わる事件：
・最後の障害：
・Bに行くきっかけ：
```

## 記入例（「あと1%で運命の恋」竜道礼本編より抜粋・要約）

```
■タイトル：あと1%で運命の恋 竜道礼 本編
■シナリオ基本仕様：全32話／1話3000字／選択肢あり／END：HE・NE（2種）

■3行ストーリー：
相性99%の彼の目的は報道ニュースの特集用「やらせ」要員！
協力しながら相性の良さを実感、1%のミスマッチに悩むも
運命の人はいたし本気の恋が運命の恋だったんだと気づくストーリー

■恋愛テーマ：相性99%の恋
■サイトならではのネタ：マッチングアプリの診断（相性数値化）

■大枠（起承転結）
起（1〜6話）：運命の恋って、突然始まるの！？
承1（7〜12話）：加速していく、運命の恋
承2（13〜19話）：1%のミスマッチの正体
転・結（20〜25話）：あの時から運命は始まってた

■ヒロインのA⇒B：
A：運命の恋なんてないでしょ？（懐疑的）
B：好きだと気づいてしまう（相性99%なのに好きになるのが怖い→本気の恋を受け入れる）

■敵：1%のミスマッチ
■味方：アプリの診断結果（相性99%）

■イベントラベル：
・価値観が変わる事件：やらせ特集の実態を知りW落胆、それでも礼のジャーナリズム精神に触れる
・最後の障害：礼が忘れられない過去の不倫恋、海外異動
・Bに行くきっかけ：空港で礼が「忘れられないのはお前」と告げる
```

## 書くときのコツ

- 3行ストーリーは「表向きの目的」と「本当の気持ち」のギャップを最初に立て、そのギャップが解消される瞬間で締めるとこのジャンルらしいトーンになる。
- 起承転結の話数レンジは総話数に応じて機械的に4等分するのではなく、「転」の直前（最後の障害）に一番厚みを持たせる配分が過去作では多い。
- ■敵／■味方は抽象的な概念（「すれ違い」等）より、なるべく具体的な固有名詞（診断アプリの数字、特定の過去の出来事）に落とすと後の話数展開がしやすい。
