# あらすじ・決め台詞（告知文）テンプレート

完結編やガチャの告知で使う短いあらすじです。長編プロットとは別に、単独ドキュメントとして作ることが多い成果物です。

## テンプレート（4点セット）

```
①一行キャッチ：（作品・エピソードの核心を一言で。例：「再婚、してください。」）
②あらすじ本文：（150字前後。句点を減らし、体言止め・体言接続を多用した圧縮文体）
③締め文句：（シリーズ名の反復＋「堂々完結」等の決め台詞）
④キャラの決め台詞：（1行。「▽新着コメント文」相当。本人のセリフとして書く）
```

## 記入例

```
①再婚、してください。

②突然の別れから3年。もう恋なんてしないと決めていたのに、
再会した彼はあの日と変わらぬ真っ直ぐな瞳で手を差し伸べてきた。
過去の傷を抱えたまま、もう一度誰かを信じられるか―
すれ違った時間を埋めるように、二人の恋がもう一度動き出す。

③サレ妻、これが本当に最後の恋。至極の男 堂々完結！

④「遅くなって、悪かった。結婚しよう」
```

## 書くときのコツ

- ②の本文は「〜だった」のような完全な文で終わらせず、体言止めで区切りながらテンポよく詰め込む。通常の地の文よりかなり圧縮した書き方でよい。
- ①のキャッチは本文を読む前に単体で成立する強さが要る。曖昧な形容（「切ない恋」等）より、状況が浮かぶ具体的な一言（「再婚、してください。」）の方が機能する。
- ④の決め台詞はキャラの口調・口癖（`character-sheet-template.md` で設定したもの）と一致しているか確認する。ここだけ口調が浮くと違和感が出る。
