# 文体ガイド

プロット作成と完成原稿（本文清書）は、このユーザーの実務では明確に工程が分かれています。プロット段階の文章をいきなり完成原稿のように書いてしまうと、後で本文を書くときにかえって書きづらくなるため、段階に応じた文体を使い分けてください。

## プロット段階の文体（大枠・ダイジェスト・詳細プロットで使う）

プロットは「執筆者への圧縮メモ」であり、小説の本文そのものではありません。以下の特徴を意識してください。

- **半角カナでの擬態語・キーワードメモ**：「ﾄｷﾒｸ」「ﾄﾞｷﾄﾞｷ」「ｷｭﾝ」「ﾋﾛｲﾝ」「ﾃﾞｰﾄ」「ｷｽ」「Ｈ」のように、感情の動きやジャンル特有のキーワードを半角カタカナで略記してよい。これは「後で正式な本文に変換する前提のメモ」というニュアンスを持つ、プロット段階特有の書き方です。
- **体言止め・助詞省略の圧縮文体**：「話す、悪くない」「もう一度愛される夜」のように、助詞を省いた圧縮表現を多用する。プロットは要約であって完成原稿ではないので、通常の小説文体より情報密度を優先してよい。
- **記号の使い方**：
  - 「！」「？」は感情の起伏に合わせて多用してよい
  - 「…」は余韻・沈黙・言いよどみを表す
  - 「（）」内はほぼ100%キャラの心の声（モノローグ）として使う
  - 「※」注記は、ト書き的な補足や制作上のメモを入れるのに使う（例：「※夜ご飯何食べた？という簡単な質問から〜」）
- **セリフと地の文の圧縮混在**：プロット段階では「」内の短いセリフと、その前後の地の文の要約が、読点や改行なしで連続してよい（例：「じゃあこれから俺と心でするSEXが本当に1番気持ちいいのか確かめよう」笑っちゃう。分かった。いいよ。）。完成原稿のように改行で分離する必要はない。

## 完成原稿段階の文体（清書・シナリオ本文を求められた場合）

ユーザーから「本文まで書いて」「シナリオにして」と言われた場合は、以下の型に切り替えてください。

- **シーン見出し**：`＜場所（時間帯）＞` の角括弧・山括弧表記で場面転換を明示する
- **セリフ行**：`キャラ名「セリフ」` を必ず単独行にする。地の文・心の声とは改行で完全に分離する。同時発話は `キャラA・キャラB「せりふ」` のように連名でまとめる
- **心の声**：セリフの前後に、独立した行で `（〜）` の丸括弧のみを使う（カギカッコとは併用しない）
- **ト書き（動作描写）**：常体の短文で、セリフの前後に独立行として挟む（例：「〜と、彼がそっと手を添える。」）
- **擬音・効果音**：単独行に配置してテンポを作る（例：「パーン！パーン！」）
- **一人称**：ヒロインの自称は「私」で固定。攻略対象は地の文では苗字・フルネームで表記し、セリフ内で相手を呼ぶ際は「お前」「アンタ」など、キャラの口調・口癖設定に沿った呼び方にする

## ジャンル別トーンの調整（新規IP・サスペンス/コメディ系の場合）

至極の男・あと1%で運命の恋・PLUSTは基本的に「溺愛×障害」の恋愛ロマンスですが、新規オリジナルIP（警察・スパイものなど）のように、恋愛以外のジャンル要素（サスペンス、組織の裏切り等）が主軸になる企画もあります。この場合、【序破急】や心の声の書き方といった骨格自体は流用してよいですが、文体のトーンは変えてください。

- 内的独白のテンポを速め、ボケ・ツッコミのリズム（「──は？」「（いや、それは…）」のような早口の自問自答）を強める
- シリアスな本筋（サスペンス回）と、キャラの素の可愛らしさを見せる軽い日常回（コメディ回）を分けて構成する運用がある。両方を1話に詰め込まず、話単位で緩急を分けるとよい
- 「溺愛モチーフ」を無理に持ち込まず、そのジャンルなりの緊張と解決（裏切りが判明する、正体を明かす等）を主軸に据える

既存の完成原稿を参照する際の注意点として、docファイル（改稿履歴のある古い版）には校正時の変更履歴（削除・挿入テキスト）がそのまま残っていて、新旧の文章が混在して見える場合があります。これはファイルの版が古いことによる見た目の問題である可能性が高いので、内容を参照する際は文脈から不自然な重複・矛盾がないか判断し、疑わしい箇所はユーザーに確認してください。

## お家芸モチーフ（参考候補・強制ではない）

過去作に繰り返し登場するモチーフです。新しい依頼の方向性に合わなければ無理に使う必要はありませんが、行き詰まったときの参考にしてください。

- **運命**：出会いや関係の進展を「運命」という言葉で意味づける
- **相性の数値化**：恋愛感情を診断アプリ等で数値化し（相性99%・体の相性100%など）、「残りの1%」が物語のミスマッチ＝ドラマの核になる構造
- **過去の傷のミラーリング**：ヒロインと攻略対象がそれぞれ別の出来事で同種の傷（不倫の記憶、離婚、大失恋など）を抱えており、それが共鳴することで急接近する構図
- **身分差・特殊な立場**：セレブ、アイドル、パイロットなど非日常的な職業・立場とのギャップ
- **マッチングアプリ・婚活**：出会いのきっかけとして頻出する設定装置

## キュン要素の作り方（過去作から見える型）

- 「ファンサ／本気」のように二重に取れる行為・セリフを用意し、真意が後からわかるミスリードを仕込む
- ギャップ萌え（俺様なのに不器用に優しい、クールなのに嫉妬する）を選択肢の分岐先で見せる
- 壁ドン・お姫様抱っこ・手が重なる、といった「型になっているスチル向けシーン」を各キャラ本編に最低1つは用意する
- キス／H描写は「一線を越えそうで越えない」焦らしと、「事後の会話で本音がこぼれる」構成を繰り返す
