# 話単位・詳細プロット（序破急）テンプレート

ダイジェストで全体の流れを確認したら、1話ずつ【序】【破】【急】の3段落に展開します。長編1話分（3000字クラスの本編）と、短編1話完結もの（受託ガチャ等）でラベルの意味合いが少し変わります。

## 長編（本編）の型

```
【序】（日常・導入。キャラの現状説明。150〜300字目安）
【破】（事件・葛藤・ピンチの発生。150〜400字目安）
【急】（急展開・解決・キュン/エロの見せ場、次話へのヒキ。150〜400字目安）
```

### 記入例（「PLUST」天満尊詠 本編より・要約）

```
【序】朝、いつも通りの同居生活。彼が寝坊してキッチンに立つヒロインをからかう。表向きのアイドルらしい笑顔と、素の軽口のギャップが日常として描かれる。

【破】ファンイベントの準備で彼の様子がおかしいことにヒロインが気づく。過去の失敗経験（現体験①）が今の彼を縛っていることが匂わされ、距離を感じるヒロイン。

【急】本音を吐露する彼。「表の顔」を保ち続けることの苦しさを初めて見せ、ヒロインだけがそれを受け止められる存在だと気づく。次話：二人の関係が一歩進む予感でヒキ。
```

## 短編（受託ガチャ・1話完結）の型

長編より単純化し、1話の中で起承転結を完結させます。

```
【序】：導入（状況説明、キャラの現状）
【破】：クライマックス直前の障害（すれ違い、照れ隠し、勘違いなど）
【急】：解決＋ENDの一言（キャラの決め台詞で締める）
```

### 記入例（「100恋+」紅崎瀧・誕生日ガチャより）

```
序：手厚いもてなしでひとしきり瀧の誕生日を祝ったヒロイン。わかりづらいが、とても嬉しそうにしてくれていることだけは伝わった。恋人同士の誕生日のお祝い、最後のシメと言ったら…

破：「この後が本番だろう？」と案の定ベッドルームに連れていかれ…そうになるのを阻止！最後のサプライズを必死で隠そうとするが、瀧にはお見通しだった。

急：事後。互いの思いやりに気づき、笑いあう。シルクの優しい感触に包まれて静かに目を閉じ、唇を寄せ穏やかでお互い癒される誕生日を過ごす二人。
```

## 選択肢を入れる場合

課金1本（厚い描写）＋無課金2本（薄い描写）の非対称構成が基本です。

```
Q：（分岐が発生する状況描写）
①（課金選択肢。♡マーク等で明示。文字数多め、本編描写が続く）
②（無課金選択肢A。文字数50〜100字程度、簡易描写で合流）
③（無課金選択肢B。同上）
```

シンプルな行動二択にする場合（受託ガチャの完結編ガチャ等でよく使われる型）は、状況説明なしで短句のみでも構いません。

```
自宅にあがる or 帰る
抱きしめられたまま or ふりきる
```

## 書くときのコツ

- 【破】で必ず何らかの「ズレ」や「誤解」を生み、【急】でそれを一気に回収する構成にすると、短い文字数でもテンポが出ます。
- 詳細プロットの文章はこの段階でもまだ完成原稿ではありません。`style-guide.md` の「プロット段階の文体」に沿って、半角カナの擬態語メモや（）モノローグを使った圧縮表現で構いません。清書（完成原稿化）は別工程として扱ってください。
- ENDを2種用意する場合は、【急】の分岐後にそれぞれの着地（HE/NEなど）を短く添える。
