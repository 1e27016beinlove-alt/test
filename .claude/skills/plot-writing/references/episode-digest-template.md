# 話数別ダイジェスト・テンプレート

大枠プロットが固まったら、全話を一覧できる「ダイジェスト」を作ります。1話=1〜数行。ここで話の流れ全体を俯瞰し、大枠のA⇒B変化やイベントラベルの位置がズレていないかを確認してから、話単位の詳細プロットに進んでください。

## テンプレート（1話ぶん）

```
○話：（要約2〜4行程度。地の文とセリフの圧縮混在でよい）
```

## 記入例（「あと1%で運命の恋」より、実際のダイジェスト密度の例）

```
7：「当然だろ？」開き直り？！礼との出会いは取材だしそばにいたADがやらせ用のアプリ特集どうです？と礼に聞いている。自分がマッチングアプリ特集のやらせの一端担わされてたと知りW落胆。じゃあ相性99％も偽り？「システムが精巧なのは裏取りしてる」偽りではないと。礼のジャーナリズム精神。やらせなのにジャーナリズムて…じゃあ礼とは相性99％本当なんだ。

8：がっくり。すると外騒がしい事故。礼一目散に現場へ。仕事ぶり見て複雑。夕方ニュース早速報道されてた。仕事熱心な礼を垣間見てしまいバーでの姿は本物だと解る。がやらせの一端担わない。あの夜運命の恋が始まるかもと思ったのになぁ。違った所詮アプリ。礼夜礼に待ち伏せ。「協力しろ」
```

## 凡例（付けておくと詳細化のときに便利）

過去作では話ごとの特性を記号で軽くマークしていました。必要なら流用してください。

```
■＝ドキ（キュンポイント）
■＝選択肢（太字は課金）
■＝謎（伏線）
■＝AtoB（価値観の転換点）
■＝シュン（しんみりする場面）
```

## 書くときのコツ

- ダイジェスト段階では文章の完成度よりも「話の推進力」が繋がっているかを優先する。1話ごとに小さな「？→！」（疑問や不安→解消や進展）があるかを意識する。
- 大枠の「価値観が変わる事件」「最後の障害」「Bに行くきっかけ」がどの話数に該当するかを、ダイジェストの該当行に一言メモしておくと、詳細プロット化のときに見失わない。
- 選択肢を入れる話は、この段階で「どちらに転んでも次の話に合流できるか」をざっくり確認しておく。
