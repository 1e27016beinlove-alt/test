# キャラクター設定シート・テンプレート

過去作（至極の男・あと1%で運命の恋・PLUST）に共通するキャラクター設定の型です。攻略対象・ヒロインどちらにも使えます。性格を一言で済ませず、この項目立てに沿って一通り埋めることで、後のプロット展開でキャラがぶれにくくなります。

## テンプレート

```
■基本情報
本名／通称・呼び名：
年齢：
誕生日・星座・血液型：
身長・体重：
出身地・学歴：
職業：

■性格の三層構造
表の顔（社会的な顔・第一印象）：
本性（素の性格）：
ヒロインへの顔（二人の時だけ見せる面）：

■経歴（生い立ち）
生育歴（要約）：
現体験①（挫折・転機となった出来事）：
現体験②（そこから現在に至る経緯）：

■詳細情報表
趣味：
特技：
弱点：（※必ず「ギャップになる弱点」を1つ含める。例：俺様なのに動物に無条件降伏、完璧なのに虫が苦手 等）
好きなもの：
嫌いなもの：
家族構成：
口調・口癖：（※具体的なセリフ例を3〜5個列挙する）
　例1：「」
　例2：「」
　例3：「」

■恋愛にまつわる設定
恋愛傾向：
葛藤・恋に落ちる要素：
問題・秘密（闇）：
いじられポイント（ギャップ）：
ヒロインへの扱いの変化（恋人になる前／なった後）：（攻略対象の場合）
```

## ヒロイン用の追加項目

ヒロインには、攻略対象と同様の項目に加えて以下も設定します。

```
恋愛傾向（ヒロインの枷）：（過去の傷。大失恋・離婚・モラハラ経験など、恋愛への懐疑や臆病さの理由になるもの）
魅力：
```

## 記入例（「至極の男」ヒロイン設定より・要約）

```
■性格の三層構造
表の顔：仕事熱心で前向きな社会人
本性：後悔しない人生を送るため、日々目の前の選択肢と戦いながら最善を選んでいるつもりでも、たまに振り返りたくなる弱い一面もある
ヒロインへの顔：―（本編で確立していく）

■恋愛にまつわる設定
恋愛傾向（ヒロインの枷）：大失恋と社会人になったことで恋は小休止中。周りの声に押されマッチングアプリに登録

■いじられポイント（ギャップ）：
小さいものに無条件で「可愛い」と反応してしまうのを恥ずかしがっている（媚びていると思われたくない）
虫が徹底的に嫌い
生理前の過食期は我慢しない（夜中でもラーメン餃子半ライスを食べ切る）
```

## 書くときのコツ

- 「表の顔／本性／ヒロインへの顔」を3つとも別の言葉で書けるかを確認する。2つが同じ内容になっている場合、まだキャラの落差が設計できていない。
- 「ギャップになる弱点」は性格的な弱さだけでなく、身体的・生活習慣的な小ネタでもよい。コメディにもキュンにも転用できる小さな欠点を1つ用意しておくと、話数展開のちょっとした場面で使い勝手がいい。
- 口調・口癖は抽象的に説明するだけでなく、必ず実際のセリフ例を書く。「俺様系」だけでは執筆時に声が定まらないが、「お前、ちょろいな」のような具体例が3つあれば書ける。
- 攻略対象が複数いるシリーズでは、キャラごとに「ヒロインの枷」との相性（どの傷とどのキャラの傷が響き合うか）を意識すると、過去作に多い「傷のミラーリング」構造が作りやすい（詳細は `style-guide.md` 参照）。
