# 「大人版」単体アダルトシーン・テンプレート

本編とは別に、既存キャラの関係性を前提とした**濃密描写に特化した短編**を単独で作る運用があります。「初夜」「性欲管理」「禁断のパラレルルート」など、テーマごとに小さなシリーズとして作られます。選択肢は基本的になし、1話2,500字程度が目安です。

## 共通の骨格

通常の大枠プロットより軽量化されますが、以下は必ず残します。

```
■タイトル：〇〇（キャラ名） 大人版　〇〇（テーマ名）
■仕様：各2,500字程度（選択肢なし）／全○話
■恋愛テーマ：（一行）
■AtoB：
A（行為・関係にまつわる開始時の心理的な引っかかり）
B（解消後の状態）
```

3行ストーリーは省略されることもありますが、**ヒロイン（またはキャラ）が抱える1つの具体的なコンプレックス・引っかかりが、行為を通して解消される**という単発の情動アークが核になります。恋愛全体のドラマではなく、「このテーマ1本」に絞って書くのがポイントです。

## テーマのバリエーション

### 1. 初夜（正式に恋人になってから初めて結ばれる話）

キャラごとに、ヒロインが抱える固有の引っかかり（バツイチによるブランク、元恋人との比較、恋人としての自信のなさ等）を設定し、それが解消されていく過程を描きます。

```
記入例（AtoBの型）：
A：Hの切っ掛け作りが分からない（レス期の後遺症）
B：恋人なんだから素直に求めるだけでいい
```

### 2. 性欲管理・射精管理（プレイフルな役割逆転もの）

「どちらかが相手の性欲を管理する」というルールを設定し、コミカルな駆け引きと本音の吐露を組み合わせるテーマです。シリアスな障害ではなく、じゃれ合い寄りのトーンになります。

```
記入例（AtoBの型）：
A：主導権を握るのは楽しい（けど満足度が足りない）
B：主導権を握ってもらう方が満たされると気づく
```

### 3. 禁断のパラレルルート（IF・非正史）

「もし別のキャラと道を踏み外していたら」という、本編の正史には影響しないパラレル企画です。禁断の関係性（元恋人、身分違いの相手など）を掘り下げる際に使われます。

- 明確に「パラレル」「非正史」であることをタイトルやテーマ欄に明記し、本編のシリアスな展開と混同されないようにする
- 読み手に「不誠実さを断罪される話」として重く受け取られないよう、**彼目線側を幸福な着地で締める**ことで読後感を調整する手法が使われている（ヒロイン視点で終えると裏切りの罪悪感ばかりが残ってしまうため）
- 制作メモとして「なぜこの終わり方にしたか」という意図をユーザーが明記していることがある。こうした注記は台本の一部ではなく、共同制作者への申し送りなので、実際の物語本文とは分けて管理する

## 制作メモ・申し送りの書き方

このユーザーは、行為描写を圧縮したプロット段階の原稿を渡す際、以下のような申し送りを添える運用をしています。ユーザーが「別の人に本文を仕上げてもらう」「今回は自分で最後まで書く」のどちらを想定しているか確認し、前者なら同様の申し送りを添えてください。

- **行為描写の粒度指定**：直接的になりすぎる箇所は圧縮して書き、「この部分は執筆担当の文体で仕上げてほしい」という一言を添える（プロット＝設計図、実際の官能描写の彩りは清書担当に委ねるという役割分担）
- **削ってよい箇所の明示**：「全ての描写を拾わなくて大丈夫です、ヒロインの心情は残してください」のように、圧縮していい部分と絶対残したい部分を分けて伝える
- **NG事項の確認**：キャラクターや媒体によって特定の行為が禁止されている場合がある（例：特定キャラは特定の行為がNG設定）。不明な場合はプロットに入る前にユーザーに確認する

## 書くときのコツ

- 通常の本編と違い、大きな障害や外的事件は不要。「行為を通じて内面の引っかかりが解ける」というミニマルな一本道の構成でよい
- 彼目線パートを混ぜる場合、行為の最中に「なぜ自分がこの行動を取るのか」という心理描写を挟むと、単なる行為描写で終わらず恋愛ドラマとしての厚みが出る（過去作でも「征服欲」「愛おしさ」等の心理注釈が必ず挟まれている）
- 半角カナの擬態語メモ、（）モノローグ、体言止め圧縮など、通常のプロット段階の文体（`style-guide.md`参照）はこのフォーマットでも共通して使われる
