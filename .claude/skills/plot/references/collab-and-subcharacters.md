# コラボ企画・サブキャラ活用のテンプレート集

## 1. コラボ企画（クロスタイトル・他社IP）

自社の別タイトルや他社IPとのクロスオーバー企画には、通常の一対一プロットにはない専用ルールがあります。

```
■最優先事項：「どちらのファンにも抵抗なく受け入れてもらえるネタか」を最初にチェックする
■ゲストキャラの扱い：名前・年齢・職業・属性のみの一覧表で紹介する。
  台詞は「ちらっといる程度」に抑え、本筋には絡ませない
■構成：総勢が多い場合は「サイドA視点／サイドB視点」を交互に配置し、
  話数の後半で両サイドが合流する会話劇形式にしてよい（1対1のフル描写にこだわらない）
■統一ギミック：全キャラ共通の「試練・お題」を1つ設定し、
  それへの「回答」だけを各キャラの個性に応じて変える
  （例：真実の愛を証明せよ、という共通のお題に対し、
   あるキャラは過去の告白を再現し、別のキャラは即興でプレゼントを作る）
■継続性チェック：過去に同種のコラボを行った実績があれば、
  そのプロット・プロローグを参照リストとして添付する
```

彼目線パートを書く際は「彼がいかにヒロインを好きで好きでたまらないか、を伝える場所」という目的を忘れないこと。事実関係の説明に寄りすぎず、感情を乗せることを優先してください。

## 2. 新キャラのお披露目（顔見せ）企画

新規キャラをいきなり本編（大枠プロット全話フォーマット）で投入するのではなく、まず軽量な短編でお披露目し、反応を見てから本編化する**2段階の投入フロー**が定着しています。

```
①顔見せ短編：3000字程度、起承転結の四幕構成、「敵/味方」欄なし（軽量）
②反応を見て本編化：人気が出たキャラから正式な大枠プロット（全話フォーマット）へ昇格
```
新キャラの初登場回だけは、通常の本編プロットにある「敵/味方」欄を持たない、より軽いフォーマットで書いてよい、という点が特徴です。

新キャラをライバル役として試験登場させる場合は「VS[既存キャラ]」の一行スペックで足ります（詳細は`campaign-formats.md`の「Season間中編」参照）。

## 3. サブキャラ・ペット活用（観察者・狂言回し型）

ペットや周辺の脇役キャラを主人公にした番外編には固有の型があります。

```
■キャラクターシート：人間の攻略キャラと全く同じ書式で作る
  （名前／職業（比喩的でよい）／性格／好きなもの 等）
■役割：「他人の恋愛模様を覗き見る」狂言回し・観察者として機能させる
  メインカップルの馴れ初め回想や現在の様子にツッコミを入れるナレーター役
■POV切り替えラベル：1本のプロット内でシーンごとに視点を切り替える場合、
  「【序】サブキャラ視点→（そのころヒロインは…）ヒロイン視点→（そのころ彼は…）彼視点」
  のようにラベルを都度差し込んで明示する
■説教役としての機能：サブキャラが人間キャラに対して「女心／男心の教育係」的に
  助言・叱責する構図も定番（例：ペットが男性キャラに女心を教える）
```

## 4. アンサンブル・ボーナスコンテンツ

複数キャラが同じ場に集まるだけの、本筋とは独立したボーナスパートです。

- **座談会**：全キャラ（またはその日登場した全キャラ）が1シーンに集合し、特定1キャラの視点で全員のかけあいを描く。周年・季節イベントの特典として使えます。
- **クロスキャラ目撃・介入**：あるキャラの話の中で、別キャラたちが同じ場面を目撃し、それぞれのキャラらしいツッコミを入れる演出。「共通導入→キャラ別分岐」の周年企画（`campaign-formats.md`）と組み合わせると効果的です。
