# 短編ガチャ・単発テーマ企画のテンプレート集

本編（1話3000字クラス、【序】【破】【急】）とは別に、1〜2話で完結する短編ガチャ・季節施策・単発ネタ企画には固有の型があります。ここを本編と混同すると、短編がやたら重厚になったり、逆に本編が薄くなったりするので、まず「本編か短編か」を判定してから該当テンプレを使ってください。

## 1. 短編ガチャの構成ラベル：「起承転結」＋場所時間ヘッダー

自社シリーズ本編は【序】【破】【急】が基本ですが、**1〜2話完結のVIPガチャ・季節施策の多くは「起・承・転・結」の4段階ラベルを使い、各パートの頭に`＠場所（時間帯）`という撮影台本的なヘッダーを付す**のが標準です。

```
【起：＠露天風呂（夕方）】…導入
【承：＠パンドラ（夜）】…展開
【転：＠彼の自宅（夜）】…事件・急展開
【結：＠彼の自宅・寝室（夜）】…着地
```
「序破急」は主に自社シリーズの長編本編（1話3000字クラス）、「起承転結＋場所時間ヘッダー」は短編ガチャ・番外編、という使い分けを意識してください。

## 2. ネガティブモチーフの甘い転化ガイド

「離婚」「喧嘩」「嫉妬」「三角関係」のような一見ネガティブな題材も、このジャンルでは定番の甘さの起爆剤として扱われます。モチーフごとに転化の型が異なります。

### (a) 記念日系（離婚記念日など）→ 意味の再定義型
暦日自体は変えず、ラベルの意味だけを反転させます。「離婚1周年」を「新しく生まれ変わった自分が始まった記念すべき日」と再定義し、キャラが花束などの具体行為で祝う。ネガティブな出来事を隠すのではなく、**「それがあったから今がある」と意味づけし直す**のがコツです。

### (b) 痴話げんか系 → 固定4幕
```
起：喧嘩の発端（弁当の中身、寝言、家事分担など些細な行き違い。深刻な対立にはしない）
承：ヒロイン視点／彼視点で同じ出来事の解釈がズレる二重視点（すれ違いの可視化）
転：どちらかが折れる小さなきっかけ（夕食を作っておく、等）
結：仲直りご褒美（H）
```

### (c) 嫉妬系（バレンタイン義理チョコ等）→ キャラ性格類型別の表出パターン
1話1000字程度の極小尺でも成立する型：「嫉妬を隠せない／隠そうとして失敗する彼」→「ヒロインがそれを可愛いと受け止める」→「甘い/ちょっと支配的な行為で締める」の3ステップ。キャラの性格類型ごとに表出パターンを変えて量産する。
- 俺様系：動揺を認めない空回り
- 甘えたがり系：拗ねる・駄々をこねる
- クール系：平静を装うが震える手を見抜かれる

### (d) 三角関係・当て馬コメディ系 → マスコット/動物キャラの起用
実際の恋愛関係を脅かさない「安全な当て馬」（ペットなど）を三角関係の相手役に起用することで、嫉妬・独占欲というモチーフを実害なく消費させる。

## 3. 単発モチーフの必須要件チェックリスト化

「壁ドン」のような1つのモチーフから、量産可能なバリエーションを作る技法です。

### (a) モチーフの辞書化
壁ドン→床ドン／ドアドン／机ドン／窓ドン／腕ドン／手ドン／肩ドン／体ドン／顔横ドン／囲いドン／エレベータードン／車内ドン／ソファドンのように、**1モチーフから派生形を体系的に列挙**してライターに選ばせる。

### (b) モチーフが機能するための必須要件（3点程度）
モチーフ単体では企画にならないため、なぜそのシチュエーションがドキドキするのかを言語化します。「密室」なら：
1. 逃げ場のないドキドキ感（物理的に閉じ込められ、強制的に一緒にいる）
2. 素の一面が見える（極限状態だからこそ普段見せない感情が露わになる）
3. 距離の近さ（物理的距離の近さ＝心理的距離の近さ）

これに加えて具体的シチュエーション事例集（高級ホテルのスイートで停電、プライベートジェットのトラブル等）をセットで用意します。

### (c) 施策全体の感情変化を1行で定義する「コンセプトの方向性」欄
キャラ単位のA⇒B変化とは別に、**施策全体としての感情の転換**を1行で定義する上位欄を用意します。
> 「閉じ込められた時間が、誰にも邪魔されないご褒美になる」“密室”のドキドキに“ラグジュアリー”の上質なムードを掛け合わせ、「逃げられない」→「離れたくない」へと感情が反転

## 4. 「彼の罠×ヒロインの罠」ペア構造

タイトル自体に両者の仕掛けを明記する対構造。
```
タイトル例：（彼の罠：パンドラでH）（ヒロインの罠：色仕掛け）
```
構成は必ず「ヒロインが彼を誘惑しようと画策する→実は彼の方が最初から仕掛けていた（＝彼の掌の上だった）」という二重の罠のどんでん返し。彼目線パートで種明かしを行います。

## 5. 軽量版・単発企画サマリーテンプレート

誕生日、周年、チャレンジ特典等の小規模施策は、大枠プロットのフルフォーマットを使わず、次の4行で立ち上げられます。
```
◆ストーリーテーマ：
◆目的：
◆文字数：
◆配信：
```

## 6. IF・パラレル系の処理：「夢オチ」フレーム

入れ替わり（body swap）のような荒唐無稽な単発ネタは、**全編を「主人公が見ていた夢」というオチで締める**ことで、シリーズの正史を壊さずに導入できます。「もしも○○だったら」IFストーリー（`special-formats.md`参照）と同じ発想で、パラレル系企画は必ず「正史に影響しない」枠組み（夢・別世界線・パラレルワールド）で処理してください。

## 7. モノを媒介にした感情開示の演出（誕生日・記念日回向け）

誕生日回は一見軽い施策に見えて、実際は「誕生日を軽視・忌避してきた過去」を持つキャラの心の傷にヒロインが向き合う、感情の深度が高い回として設計されることが多いです。**具体的な小道具（ペン、消しゴム、スパイス、オムライスなど）を伏線として過去の傷を語らせる**技法が共通しています。「ギャップになる弱点」（`character-sheet-template.md`）とは別に、**小道具1つを過去開示のトリガーとして仕込む**という独立した演出技法として使えます。

## 8. ラフ下書き（着想メモ）という前段階

正式なpptxプロットを起こす前に、**全キャラ分のあらすじを1つのテキストファイルに箇条書きでまとめる**着想メモの段階があります。この段階では「敵/味方」等の欄はまだ書かず、単純な地の文の要約のみ。ユーザーが「まずラフにアイデア出しをしたい」と言った場合は、大枠プロットのフルフォーマットではなく、この軽量な箇条書きメモから始めるのが実務に近い進め方です。
