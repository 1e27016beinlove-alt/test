# 大型定例企画のテンプレート集（周年・完結前番外編・親密度・総選挙）

シリーズが長期運用に入ると、通常の本編・単発ガチャとは別に「毎年・毎回同じ枠で繰り返す」定例企画が発生します。ここでは、そうした定例企画特有の型をまとめます。いずれも8年以上運用されているフォーマットで、安定して使い回せます。

## 1. 周年施策（1周年〜9周年）

周年施策には大きく2つのバリエーションがあります。どちらを使うかは企画意図次第です。

### (a) 回想・再告白型（主に初期〜中期の周年で使用）
既存本編中の具体的なエピソード（小道具・出来事）を引用しながら、カレが「もう一度好きになった瞬間」を振り返り、あらためて想いを伝える構成。

```
■Uへの提供価値：もう一度ヒロインを好きになった瞬間を彼が思い出し、惚れ直すストーリー
■入れてほしい要素：関係性の歴史を感じさせる回想／カレなりの再告白（言葉にしなくてもOK）
```
本文内で「エプロンをプレゼントした話」「怪我の手当てをした話」のように**過去の具体エピソードを固有名詞つきで回想**するのがポイントです。ゼロから新しい葛藤を作らず、これまでの積み重ねを再確認させます。

### (b) 非日常体験×溺愛オムニバス型（主に後年・大型周年で使用）
クルージング、気球、高級ホテルなど「彼が普段連れて行かない特別な場所」を毎回変えるだけの構成で、複数キャラに横展開する量産型。タイトル案は1本ではなく**2〜3案を併記**してクライアントに選ばせる運用が定着しています（例：「世界一贅沢な再確認～君が1番な理由～」「全部君のため。溺愛彼氏のエスコート」）。

### (c) ステータス初期化型
既に恋人・夫婦であるキャラの関係を一時的に「まだ落とす前の駆け引き期」相当まで巻き戻し、口説かれ直すドキドキを再演出する企画。
> 「現在は長年交際し強固な絆では繋がれているものの、付き合う前の駆け引きやドキドキは軽減している。そこでステータスを初期に戻すことで、相手の好意に一喜一憂したり、駆け引きしたり、そんな恋したての楽しみを味わえるストーリー」

### (d) 全キャラ横断クロスオーバー型
複数タイトル・キャラが一堂に会するイベント（パーティー等）に紛れ込むという共通導入を作り、A/B選択肢で登場キャラ群が分岐し、最後の1択だけ「1人のみ登場」に収束させて個別ロマンスへつなげる**二層構成**（マスイベント→個別ロマンス）。管理表（xlsx）では選択肢ごとに「♡数／円／字数／メインキャラ／他登場キャラ／無課金」を1行で持たせます。

### (e) 「一生の誓い」型
カレが「一生○○し続ける」と誓う一言をコアバリューにするミニマム構成。**「誓ってくれる内容が軽いものになり過ぎないよう留意」**という重み担保の注意書きを忘れないこと。

### 周年企画で使えるアンサンブル演出
- **クロスキャラ目撃・介入演出**：あるキャラの話の中で、別キャラたちが同じ場面を目撃し、それぞれのキャラらしいツッコミを入れる（「共通導入→キャラ別分岐」の型に、他キャラの通りすがりコメントを差し込む）
- **事後座談会**：全キャラが1シーンに集合し、特定1キャラの視点で全員のかけあいを描くボーナスコンテンツ。本編とは独立した商品として企画できる

## 2. 完結事前告知番外編

完結を発表する"前"に打つ番外編には、通常のガチャ企画と異なる明確な設計ルールがあります。

```
■方針：新しい事件・葛藤を作らない。既存の伏線を再提示するだけに徹する（大きいネタは仕込まない）
■ターゲット：長期間配信がなくても待ち続けてくれた休眠ユーザーの掘り起こし
■構成：全キャラ共通の群像劇プロローグ（例：「メンバーが再会する」）→各キャラ個別の後日談へ分岐
```
新規消費喚起が目的の通常ガチャとは目的が異なり、**「リマインド」に徹する**のが最大の特徴です。

## 3. Season間中編（アフター編）

完結編でも番外編でもない、Season同士の間に挟む15話+彼目線5話程度の中編。**新キャラ（現在はサブキャラ）を本命の対抗馬として「VS」形式で試験登場させ、将来の本編化に向けた反応を見る**という新キャラお披露目の型を兼ねます。

```
■VS表記例：笠椿颯力（大病院会長）VS瀧／ブラッドムーン VS潔人
```
ライバルはフルのキャラ設定ではなく、**因縁・属性を一行で示す軽量スペック**で足ります。ストーリーは「ヒロインが元恋人や新キャラに誘惑されるが、最終的に本命を選び続ける」という貞操ストレステスト構成が典型です。

## 4. 親密度キャンペーン（親密度スト第○弾）

```
■命名：「〇〇親密度スト第○弾」（通し番号必須）
■ボリューム：2,000字×6〜10話が目安、選択肢なし（一本道の甘さ描写）
■対象読者：親密度が高いコアユーザー限定であることを明記
■甘さレベルの接続：前作の続きからではなく、少し戻した状態からスタートし、話数が進むごとに再度エスカレートさせる
```
**「秘密の相互開示」装置**（鍵付き日記など）は複数キャラで使い回しつつ、キャラごとに中身（口調・記録内容）を変えることでキャラ性を出す量産手法として有効です。

## 5. 総選挙・人気投票関連施策

### 順位帯×親密度マッピング
上位ほど長時間・高密着なシチュエーションになるよう、順位と物語内容を連動させます。

| 順位帯 | デートテーマ | 時間軸 |
|---|---|---|
| 1〜5位 | 翌日まで一緒（お泊まり） | 深夜〜翌朝 |
| 6〜10位 | 夜までデート | 終電間際まで |
| 11〜20位 | お昼デート | ランチのみ、爽やか |

### 最小フォーマット「WEBコン」
地の文なし、セリフのみで完結する超短文コンテンツ。人気投票の広い母数に安く大量配布する最下層アイテムとして使えます。
```
■仕様：1キャラあたり225字（45字×5セリフ）
■提供価値の例：疲れて帰宅したら…彼が優しく「おかえり」出迎えてくれて癒される
```

### ユーザー個別オーダーメイド企画のインテークシート
総選挙上位入賞者向けの特典は、アンケートで要望を収集してから執筆します。

```
■収集項目：デートで行きたい場所（第一〜第三候補）／したいこと／その他の希望・お願い
■必須の注意事項：
- 他ユーザーが知らない未公開情報・今後の設定に影響する要素はNG
- ストーリー内の出来事は今後の展開に反映しない（パラレルワールド扱い）
- 新規アイテム・キーとなる小道具は出さない
```
ユーザー要望はプロット内に「※緑部分はU様のご要望※」のように色分け転記して執筆者に伝える運用が確認されています。
