# 特殊フォーマット集（キャラ愛施策・IF企画・クロスキャラ）

通常の本編プロット（大枠→ダイジェスト→詳細）以外に、季節施策やイベント企画で使われる派生フォーマットです。依頼の性質に応じて使い分けてください。

## 1. キャラ愛施策・ミニストーリー連鎖

平日に短いミニストーリーを複数話連鎖させ、週末に本編で着地させる構成です。「時系列で①→②→③→④が進むこと」を発注書・プロット双方に明示するのが特徴です。

### テンプレート

```
■施策名：（例：「ご褒美キス計画」「キャラ愛_夏旅施策」）
■構成：
①（500字程度・ヒロイン目線が基本、カレ目線可）
②（500字程度）
③（500字程度）
④週末本編（1500〜2000字）

■時系列の流れ：①→②→③→④で自然に日付・状況が進むこと
■テーマ：（施策全体を貫く一言。例：「旅行の計画を立てる高揚感」）
```

### 記入例（「夏旅施策」より要約）

```
①旅行のお誘い（月曜）：カレから唐突に旅行の提案。行き先はまだ秘密
②準備（水曜）：荷造りしながら二人でわちゃわちゃ。何を着ていくか相談
③前日（金曜）：待ちきれない気持ちが高まる。ちょっとしたすれ違いも
④週末本編：当日、旅先でのメインイベント（ちょっとした試練→キュンの着地）
```

### 書くときのコツ

- ①〜③は「本編の前振り」に徹し、各話単体で大きな事件を起こさない。小さな日常の積み重ねが週末本編への期待値を上げる役割を持つ。
- 週末本編（④）だけは通常の【序破急】構成でしっかり組み立てる。①〜③がダイジェスト、④が詳細プロットに近いイメージ。

## 2. IFストーリー（パラレル設定）

「もしも○○が××だったら」という、既存キャラの設定を一時的に変えたパラレル企画です。通常の本編より軽量なフォーマットで済みます。

### テンプレート

```
■一行コンセプト：「もしも〇〇が××だったら」
■提供価値：（3〜4項目の箇条書き。例：「普段と違う一面が見られる」「甘え方のギャップにキュンとする」）
■仕様：文字数・話数
■【序】【破】【急】：（短編の三幕構成でよい）
```

### 記入例

```
■一行コンセプト：もしも大門が甘える彼氏だったら
■提供価値：
・普段は俺様な大門が素直に甘えてくる姿とのギャップ
・「もしも」だからこそ許される、いつもと違う距離感
・現実の大門ルートでは見られない少年っぽい一面

【序】いつも通り強気な大門。だが今日はやけに機嫌が良く、ヒロインにべったり
【破】理由を尋ねると「もしお前が一日だけ俺の言うこと聞いてくれるなら」と甘えた条件を出してくる
【急】素直に甘える大門にヒロインもドキドキ。「これが素の大門だったら」という余韻を残して締める
```

### 書くときのコツ

- 「もしも」の設定は性格の根本を変えるのではなく、普段抑えている面を解放するくらいの振れ幅にすると、既存のキャラクター設定（`character-sheet-template.md`）と矛盾しにくい。

## 3. クロスキャラ（複数キャラ横断）三部構成

1つの物語装置に複数キャラが絡む、3話セットの企画です。嫉妬・介入モチーフと相性が良い構成です。

### テンプレート

```
■構成：
①本命キャラとの日常（メインの関係性を描く）
②他キャラとの介入エピソード（本命が同じ場に居合わせる、または後で知る）
③本命キャラの嫉妬・彼目線（①②を受けての反応）

■狙い：（例：「嫉妬させることで本命の独占欲を引き出す」）
```

### 記入例（「7月火遊び」施策より要約）

```
①本命（駿）と二人で夏を満喫。海辺デートで甘い時間
②別キャラ（開生）が偶然同じ海に来ており、ヒロインと軽く絡む「火遊び」的なちょっかい
③駿目線：②の様子を目撃し、素直に嫉妬。「他の男に見せる顔と俺に見せる顔、違うだろ」と独占欲を見せる
```

### 書くときのコツ

- ②の他キャラとの絡みは、あくまで③で本命の嫉妬を引き出すための装置。②単体で恋愛関係が進展しすぎないよう、関係性の主役は常に①③の本命キャラに置く。
- ③の彼目線は `outline-template.md` の「彼目線のA⇒B」を単独で設定し、ヒロイン目線のA⇒Bと混同しないようにする。

## 4. 新規オリジナルIP（サスペンス／コメディ寄りの長尺連続もの）

至極の男・あと1%で運命の恋・PLUSTのような「溺愛×障害」ロマンス以外に、警察・スパイものなどサスペンス色の強い長尺連続ストーリーが新規タイトルとして走ることがあります。

- 大枠プロット・話数ダイジェスト・【序破急】という骨格自体はそのまま使える
- ただし主軸の緊張と解決は「恋愛のミスマッチ」ではなく「サスペンス上の謎・裏切り」に置く
- シリアスな本筋回とキャラの素を見せるコメディ回（日常回）を分けて構成し、1話に詰め込みすぎない
- 文体はボケ・ツッコミ寄りの内的独白（テンポの速い自問自答）を強める。詳細は `style-guide.md` の「ジャンル別トーンの調整」を参照
