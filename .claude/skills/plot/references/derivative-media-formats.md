# 派生成果物・特殊メディアのフォーマット集

本編ストーリー以外に、同じ施策の中で並走する派生成果物や、音声・出版など別メディア向けの特殊フォーマットです。ユーザーから依頼を受けたら、まず「本編ストーリーだけでよいのか、派生アイテムも必要か」を確認してください。

## 1. 本編と並走する派生成果物（2025〜26年の標準構成）

大型施策では「本編ストーリー＋派生アイテム」の多層構成が標準になりつつあります。

### 5TAPミニスクリプト
社内制作と明記される短尺の追加コンテンツ。**ト書き不要・セリフのみ**で場面を成立させます。
```
■5TAPミニスクリプト ※社内制作
入れる要素：ヒロイン目線の夜
※ト書き不要、セリフのみ
```

### 台詞パック
ストーリー本編とは別に、**セリフ単体を並べるだけの管理表（xlsx）**。
```
列構成：NO. ／ セリフ（45文字目安） ／ 表情タイプ（記号）
```
シーンやト書きを伴わない、単発ボイス／スタンプ的なセリフ集です。

### 待受（壁紙）テキスト
100文字程度の一言。「ストーリー2話＋台詞パック＋待受」で1キャンペーン=3点セットになる運用があります。

### WEBコン（最小フォーマット）
地の文なし、セリフのみで完結する超短文（`campaign-formats.md`の総選挙施策を参照。45字×5セリフ＝225字が目安）。

## 2. ボイスドラマ台本

通常のプロット・完成原稿とは根本的にルールが異なります。声優が音読する前提で書くため、以下を必ず守ってください。

```
1. キャラ名呼び禁止：収録上、名前を呼ぶと不自然なため「彼女」「あいつ」等に変換する
2. セリフのみで進行しない：ヒロインの発話は、彼による復唱かト書きの音読で処理する
   悪い例：ヒロイン「誰か人が来たらどうするんですか！」／彼「この時間じゃ誰も来ねえよ」
   良い例：彼「誰か人が来たら…って、この時間じゃ誰も来ねえよ」（ヒロインの発話を彼が先取りして復唱）
   または：ト書きで「人が来たらどうしようと赤くなって慌てる彼女を、腕の中に引き留める。」
          （※このト書きも声優が読み上げる前提で書く）
3. 過度な性描写は避ける（直接的な行為描写はNG）
4. ダミーヘッド（バイノーラル）収録を想定した位置関係を明示する：
   彼が近い/遠いか、正面/隣か、立位/臥位か、ヒロインから見て左右どちらにいるか
5. 各シチュエーションは単話で完結させる（前後のエピソードに依存する構成はNG）
6. リップ音・攻める描写の演出強度は「抑えめ」に指定する
```

このフォーマットが必要かどうかは、依頼の時点でユーザーに確認してください。通常の完成原稿フォーマット（`style-guide.md`）とは別物として扱う必要があります。

## 3. コミカライズ・単行本特典（クリップショー型）

完全新規執筆ではなく、**既に配信済みの「彼目線」ストーリーからシーンを抜粋・再構成する**企画です。

```
工程1：既刊シーンの「ピックアップリスト」を作る
  例：【彼目線1話目 ピックアップ 夫に離婚切り出すシーン～ハウスキーパーとして契約】
工程2：合間に「新情報」（新規書き下ろしの短い追加パート）を挟む
工程3：シーン名ラベルを削除し、地の文で自然につないだ一続きの読み物として再構成する
```
単なる総集編（羅列）で終わらせず、工程3で「一続きの物語」として整形するのがポイントです。

## 4. キャラ紹介ダイジェスト（ヴィネット集）

新規ユーザー向けに「このキャラの魅力を密着紹介する」企画です。通常の話数連番プロットとは異なり、**独立した1シーンずつを積み重ねるヴィネット（短編集）形式**で、一貫したプロット線を持たせません。
```
＠公園（昼）
＠彼の自宅・ヒロインの寝室（夜）
（…各シーンが独立、通しの事件は不要）
```
雑誌企画のメタ演出（「袋とじ」「あとがき」など、限定コンテンツ風の飾り）を作中に組み込む手法も使えます。
